# 00_ai_operating_model — HISTORICAL (marked 2026-07-30, user-ratified)

**Everything in this directory describes a multi-agent operating fiction from the project's genesis
(2026-06-18) that was never how the platform was actually built.** The "R-01 Product Manager AI /
R-02 Chief Architect AI" specialist-role registry, the automation hooks, and the master build prompt
were superseded in practice from the first delivery slice onward by the REAL operating model:

- **`docs/project_memory/claude_operating_instructions.md`** — the operative cadence, standing rules
  (P1–P7 + companions), gate tiers, and engineering conventions;
- **`CLAUDE.md`** (repo root) — the auto-loaded entry pointer and hard invariants;
- **`10_delivery_backlog/delivery_roadmap.md`** — the operative rolling-wave sequence.

These documents are retained verbatim as history: they are cited by early ADRs and requirement
records, and `reconciled_agent_role_registry.md` remains in the docs-check Document Control set. Two
pieces remain live REFERENCE rather than history: the R-01…R-xx / H-xx role IDs used as Owner/
Approver fields across the governance docs, and `bau_ai_use_cases.md` as the CAP-19 requirements
source. Nothing here overrides the operative documents above — where they disagree, the operative
set wins.
